# JustiTeX Web Studio Components

Harvested from `terra-plaza-zenith-cap`.
Provides React / Tailwind web components for live 28-line Oregon & Federal pleading paper rendering:
- `pleading-paper.tsx`: True-to-scale 28-line UTCR pleading paper with line numbering gutter and double left rule.
- `pleading.ts`: Jurisdiction definitions (`or-circuit`, `or-appeals`, `d-or`, `ca9`, `federal`), caption formatters, and pagination engine.
- `studio.tsx` & `office.tsx`: Interactive drafting studio and office UI routes.
- `rag.ts`: Client-side citation retrieval helper.
